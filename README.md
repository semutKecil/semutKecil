# 🚀 From Friendster CSS to Kubernetes Clusters: My Engineering Journey

> *"I didn't start coding because I wanted to build enterprise software. I started coding in 2006 because my Friendster profile needed custom styling."*

---

### **Act I: The Gateway (2006 – 2012)**

* **The Origin:** Tweak CSS on Friendster led to building personal sites using **Joomla, WordPress, and Drupal**.
* **First Code:** To get past CMS limitations, I picked up **PHP** alongside **HTML, CSS, JavaScript**, and **jQuery**.
* **Framework Era:** Leveled up from raw scripts into early backend frameworks like **Zend, Symfony, Silex**, and **CodeIgniter**.

---

### **Act II: Going Pro & The Enterprise Shift (2013 – 2017)**

* **Junior Dev (2013):** Started my career writing PHP and mastering **ExtJS** for heavy web dashboards.
* **The Java Pivot:** When app requirements grew heavier, our company migrated to **Java + Spring Framework**. I adapted to strong typing and enterprise patterns.
* **The Kotlin Upgrade:** The moment **Kotlin** matured, my team and I rewrote our applications using **Kotlin + Spring Boot** for cleaner, safer code.

---

### **Act III: Mobile, Desktop & Tooling (2018 – Present)**

* **Native Android to Flutter:** Learned native Android (Kotlin) first, then transitioned our team to **Flutter / Dart** to build multi-platform apps efficiently.
* **C# / .NET for Low-Level Windows:** Used C# whenever we needed direct Windows API bridging (like high-volume SQL Server bulk inserts).
* **Dart for Internal Tooling:** Discovered how great **Dart** is for building fast CLI tools, making internal team workflows smoother.

---

### **Act IV: Infrastructure & Modern Engineering**

* **Daily Drivers:** **Kotlin (Spring Boot)** on the backend, **Dart / Flutter** for multi-platform frontends.
* **DevOps Operations:** Actively managing company infrastructure with **Git, Docker**, and maintaining production **Kubernetes (k8s)** clusters.
